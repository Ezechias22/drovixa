# Drovixa logo assets

The original supplied artwork is preserved at
`mobile/assets/drovixa-logo-full.png` (1254 × 1254). Generated application
variants keep the original artwork intact and are optimized for each client:

| Target | File | Size |
| --- | --- | --- |
| Expo/iOS icon | `mobile/assets/icon.png` | 1024 × 1024 |
| Android adaptive foreground | `mobile/assets/adaptive-icon.png` | 1024 × 1024 |
| Expo splash | `mobile/assets/splash-icon.png` | 1200 × 1200 |
| Responsive Web brand | `web/public/brand/drovixa-logo.png` | 768 × 768 |
| PWA large icon | `web/public/icons/icon-512.png` | 512 × 512 |
| PWA standard icon | `web/public/icons/icon-192.png` | 192 × 192 |
| iOS Web clip icon | `web/public/icons/apple-touch-icon.png` | 180 × 180 |
| Browser favicon | `web/public/icons/favicon-48.png` | 48 × 48 |

The Android adaptive variant contains a safe margin so launchers can apply
circle, squircle, rounded-square, or other masks without cutting the Drovixa
mark. Web and React Native components use responsive dimensions and preserve
the image aspect ratio.
