# Drovixa security policy

Do not open a public issue containing credentials, private playback URLs,
personal data, payment information, or an exploitable vulnerability.

Before public launch, replace `SECURITY_CONTACT_TO_CONFIGURE` below with the
monitored security email or private reporting form used by Drovixa:

`SECURITY_CONTACT_TO_CONFIGURE`

Include the affected surface, reproduction steps, impact, and a safe proof of
concept. Drovixa should acknowledge valid reports within three business days,
triage severity, rotate exposed credentials immediately, and coordinate a fix
before public disclosure.

Supported security releases begin with `0.12.x`. Older preview builds should be
updated before troubleshooting.
